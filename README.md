# Ay Işığında İmza Bekleyen Horoz

> Resmî adı: Ay Işığı Altında İzinsiz Ötüşü Önleme ve Geciktirme Genel Komutanlığı, Kısa Adı Hık.

Bu depo bir şakadır. Ama şakayı ciddiye alan bir şakadır. Horoz ötmek ister. Ay ışığı buna tarafsız bakar. Komşu ise tarafsız bakmaz. Araya dört daire girer. Dört daire imza atmadan horozun sesi, evrak açısından, henüz doğmamış sayılır.

Patates yoktur. Patates başvurusu reddedilmiştir. Gerekçe: konuyla ilgisi yoktur, üstelik toprak altındadır, mühür tutmaz.

## Ne işe yarar

`horoz.py` gerçekten çalışır. Python 3 yeter. Kütüphane istemez, çünkü bürokrasi zaten kendi başına ağırdır.

Horozun adını, mahalleyi ve talep edilen saati alır. Dört daireden geçirir:

1. Ay Işığı Ölçüm Dairesi
2. Horoz Sicil Müdürlüğü
3. Komşu Uyku Hakkı Şubesi
4. Mühür Mürekkebi Genel Müdürlüğü

Hepsi onaylarsa ötüş izni çıkar. Biri takılırsa dosya “ek evrak” diye geri döner. Sonuç, girdiye göre sabittir: aynı horoz, aynı mahalle, aynı saat, aynı kader. Bürokrasi böyle adildir. Adaleti de böyle saçmadır.

## Çalıştırma

```bash
python3 horoz.py --horoz Şahin --mahalle "Kedi Çıkmazı" --saat 03:17
```

İzin çıkmazsa horozun adını değiştirin. Sicil müdürlüğü isimlere zayıftır. “Papatya” bazen “Şahin”den daha kolay öter. Bunun sosyolojik açıklaması yoktur. Mürekkep açıklaması vardır.

## Neden var

Çünkü bir horozun gece yarısı ötmesi, dört imzadan daha az evrak gerektirmemeliydi. Bu cümle ciddidir. Ciddiyeti de komiktir. İkisi aynı masada oturuyor, çay ısmarlamadılar, çünkü çay da ayrı bir daireye bağlı.
